# Webhook Solution - JAR Releases

## Latest Release

**File:** `webhook-0.0.1-SNAPSHOT.jar`

This is the compiled Spring Boot application ready to run.

### System Requirements

- **Java 8 or higher** (Java 8, 11, 17, 21, etc.)
- Check your Java version: `java -version`

### How to Use

1. **Download the JAR file** from this folder
2. **Run the application from Command Line:**
   ```bash
   java -jar webhook-0.0.1-SNAPSHOT.jar
   ```
3. The application will start on port **8080** with Tomcat webserver

### Troubleshooting

**If you get "UnsupportedClassVersionError":**
- You likely have an older Java version than Java 8
- Download Java 8 or later from: https://www.oracle.com/java/technologies/downloads/

**To check your Java version:**
```bash
java -version
```
